## 5. 비기능 요구사항
- **반응형 디자인**: 모바일(360px~) / 태블릿 / 데스크톱 대응
- **성능**: 정적 페이지 기반으로 빠른 로딩
- **접근성**: 시맨틱 HTML5 태그(`header`, `nav`, `section`, `footer`) 사용, 이미지 대체 텍스트 제공
- **SEO**: 메타 태그(title, description, Open Graph) 설정
- **호환성**: 최신 Chrome, Edge, Safari, Firefox 지원

## 6. 기술 스택

- **백엔드(선택)**: Python (Flask 또는 FastAPI) — 문의 폼 처리 등 필요 시
